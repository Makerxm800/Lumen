# Lumen Player

A desktop media player for your local music and videos, built with Electron. Lumen brings playback, a persistent media library, and a play queue together in a responsive dark interface.

## Download

The latest release is **[Lumen v1.4.0](https://github.com/Makerxm800/Lumen/releases/tag/v1.4.0)**. It includes Windows x64 and macOS builds (Intel and Apple silicon).

## Highlights

- Organize and search a local audio/video library; add files or scan folders.
- Play, seek, adjust speed and volume, shuffle, repeat, and choose audio or subtitle tracks.
- Preview video frames while scrubbing inline-playable videos, without subtitle overlays in the preview.
- Zoom and pan supported videos, or compare two videos side by side.
- Keep playback preferences and library sorting between launches.
